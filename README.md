# 911 – Грузовая эвакуация

Лендинг по ТЗ «911 – Грузовая эвакуация». Дирекция: тёмный технический стиль (графит + сигнальный жёлтый), контент и контакты из ТЗ и [penza-evakuator.ru](https://penza-evakuator.ru/).

## Запуск

```bash
pnpm install
pnpm dev
```

Открыть: [http://localhost:3456](http://localhost:3456)

- `/` – выбор варианта
- `/v1` – вариант 1 «Ночной диспетчер» (тёмный + жёлтый)
- `/v2` – вариант 2 «Свежий сигнал» (светлый + coral, Unbounded)
- `/v3` – вариант 3 «Launch black» (SpaceX-like: чёрный void, Oswald, uppercase)

## Где что лежит

| Путь | Назначение |
|------|------------|
| `src/data/site.ts` | Телефоны, адреса, тарифы, FAQ, тексты |
| `src/app/globals.css` | Токены `.theme-v1` / `.theme-v2` |
| `src/components/v1/` | Макет варианта 1 |
| `src/components/v2/` | Макет варианта 2 |
| `src/components/` | Общие формы, калькулятор, FAQ |

Смена палитры: правьте CSS-переменные в `:root` внутри `globals.css`.

## Демо / заглушки

- Формы и калькулятор **не** шлют заявки (подписано в UI).
- Фото эвакуаторов, кейсы, Telegram/MAX, карта, надбавки – `[ЗАПОЛНИТЬ]`.
- Политика и согласие – текстовые заглушки под юриста заказчика.

## Стек

Next.js (App Router) + TypeScript + Tailwind CSS v4. Шрифт Manrope (400/700, кириллица), OFL via Google Fonts.
